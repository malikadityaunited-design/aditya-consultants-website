# ADITYA CONSULTANTS website

Static Vercel-ready site with India and the UK presented as distinct markets and cross-border advisory as an additional service.

## Contact form

The browser checks required fields and email format, then opens the visitor's default email application with an enquiry addressed to adityamalik@atomicmail.io. Name, reply email, selected market, service and message are prefilled. The visitor reviews and sends it. No enquiry is transmitted or stored by the website. Visitors without a configured email app can use the direct email link.

## Deploy with Vercel

Sign in at https://vercel.com/, create a project, and import this folder from a Git repository or deploy the folder with Vercel CLI. Select Other as framework preset, leave the build command empty, and set the output directory to the current folder. Deploy; Vercel displays the URL on success. Project names and their vercel.app addresses depend on availability.
